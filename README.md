## 지도서 기준으로 지킨 것
- 화살표는 **먹히는 생물 → 먹는 생물** 방향
- 생산자를 설명할 때 광합성 원리는 다루지 않음
- 분해자는 버섯·곰팡이·세균 정도
- '생태계평형' 용어는 쓰지 않고 "먹이그물이 복잡할수록 안정적으로 유지될 수 있다"로 표현
- 환경오염은 대기·수질·토양오염 중심

진행 기록은 학생 기기의 브라우저에만 저장되며 어디로도 전송되지 않습니다.
