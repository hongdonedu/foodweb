제미나이로 로고·버튼·그림 만들기

한 대화방에서 이어서 만들면 그림체가 통일됩니다. "같은 그림체로"를 꼭 붙이세요.

1이미지 만들기 켜기

  1. gemini.google.com 접속
  2. 입력창 왼쪽 ＋ 누르기
  3. 이미지 만들기 선택 → 입력창에 '이미지' 칩이 생기면 준비 끝
팁 모델은 Pro가 한글 글씨를 더 정확하게 씁니다. 버튼에 '탐험 시작'처럼 한글이 들어가도 깨지지 않았어요.

2로고 주문하기

무엇을, 어디에, 어떤 색·그림체로, 배경은 어떻게 — 네 가지를 한 문단에 씁니다.

로고 프롬프트 초등학교 4학년 과학 웹앱 「먹이그물 탐험대」의 로고를 그려 줘. 가운데에는 둥근 배지 안에 벼 → 메뚜기 → 개구리 → 매가 화살표로 이어진 모습, 아래에는 굵고 귀여운 한글 글씨 '먹이그물 탐험대'. 밝은 초록·하늘색·노란색을 쓰고 두꺼운 외곽선의 스티커 그림체로. 배경은 아무것도 없는 단색 흰색, 정사각형.

3과학 선생님의 눈으로 검토하고 고쳐 달라고 하기

첫 결과는 예뻤지만 벼 → 개구리, 양쪽 화살표처럼 과학적으로 틀린 화살표가 있었습니다. 지도서 기준(화살표는 먹히는 생물 → 먹는 생물)을 알려 주고 고쳐 달라고 했더니 바로 고쳐졌어요.

수정 프롬프트 좋아! 그런데 과학적으로 틀린 화살표가 있어. 화살표는 '먹히는 생물 → 먹는 생물' 방향이야. 벼→메뚜기, 메뚜기→개구리, 개구리→매 이렇게 한 방향 화살표 3개만 남기고 나머지 화살표(벼→개구리, 양쪽 화살표, 메뚜기→매)는 모두 지워 줘. 나머지 그림과 글씨는 그대로.
꼭 확인! AI 그림은 그럴듯하지만 틀릴 수 있어요. 화살표 방향, 생물의 생김새, 글자 맞춤법은 교사가 최종 검토합니다. 이 장면 자체가 좋은 수업 소재가 됩니다.

4같은 대화방에서 버튼·배경·스티커·캐릭터 이어서 주문하기

버튼 고마워! 이제 같은 그림체로 이 웹앱에 쓸 게임 버튼 4개를 한 장에 그려 줘. 위에서부터 한 줄에 하나씩: ① 초록색 '탐험 시작' ② 하늘색 '다음' ③ 주황색 '다시 하기' ④ 노란색 '정답 확인'. 둥근 알약 모양에 살짝 입체감, 글씨는 흰색 굵은 한글(정답 확인만 갈색 글씨), 버튼 사이 간격은 넉넉하게, 배경은 아무것도 없는 단색 흰색.
배경 좋아! 이번에는 같은 그림체로 웹앱 첫 화면 배경 그림을 16:9 가로로 그려 줘. 왼쪽은 숲과 풀밭, 가운데 아래는 논, 오른쪽은 연못이 있는 맑은 날의 풍경. 동물과 글씨는 넣지 말고 풍경만, 가운데 윗부분은 제목을 올릴 수 있게 하늘을 넓게 비워 둬. 색은 밝고 부드럽게.
스티커 시트 이번에는 같은 그림체로 생물 스티커 16개를 4×4 격자로 한 장에 그려 줘(정사각형). 스티커마다 두꺼운 흰 테두리, 스티커끼리 겹치지 않게 간격 넉넉하게, 배경은 단색 마젠타(#FF00FF), 글씨는 넣지 마. 각 생물은 전신이 다 보이게. 순서: 1줄 벼, 배추, 검정말(물속 수초), 식물성 플랑크톤 / 2줄 메뚜기, 배추흰나비 애벌레, 토끼, 새우 / 3줄 참새, 개구리, 붕어, 오리 / 4줄 다람쥐, 뱀, 왜가리, 매.
캐릭터 마지막으로 같은 그림체로 앱의 안내 캐릭터를 그려 줘. 초록 탐험 모자와 카키색 조끼를 입은 귀여운 초등학생 탐험대장(돋보기를 들고 있음). 한 장에 같은 캐릭터 포즈 3개를 가로로 나란히: ① 손 흔들며 인사 ② 엄지 척 칭찬 ③ 돋보기로 관찰하며 고민하는 표정. 두꺼운 흰 테두리 스티커, 포즈끼리 겹치지 않게, 배경은 단색 마젠타(#FF00FF), 분홍·보라색은 쓰지 마, 글씨 없음, 16:9 가로.
왜 마젠타(분홍보라) 배경? 자연물에는 거의 없는 색이라 나중에 배경만 쏙 지우기 쉽습니다. 흰 배경도 괜찮아요. 그림을 흰 카드 안에 넣는 디자인이면 배경을 지우지 않아도 자연스럽습니다.

5내려받고 이름 붙이기

  1. 그림 위에 마우스를 올리면 나오는 ⬇ 원본 크기 다운로드 누르기
  2. 내려받은 파일 이름을 영어 소문자로 바꾸기
    logo.png bg.jpg btn_start.png …
  3. 스티커 시트는 한 장씩 잘라 frog.png처럼 저장
    (캔바 ▶ 사진 업로드 ▶ 자르기·배경 제거 → PNG 다운로드)
  4. 앱 폴더 안 images 폴더에 모으기
이름 규칙 한글·띄어쓰기·대문자는 피하세요. 깃허브 주소에서는 Logo.png와 logo.png가 다른 파일입니다.
먹이그물탐험대/ ← 이 폴더째 올립니다 ├─ index.html ← 첫 화면 (이름 그대로!) └─ images/ ├─ logo.png bg.jpg ├─ btn_start.png btn_next.png btn_retry.png btn_check.png ├─ guide_hi.png guide_good.png guide_think.png ├─ org/ frog.png hawk.png rice.png … (32개) └─ env/ factory.png recycle.png … (16개)

그림을 앱에 넣는 프롬프트 — 파일 이름으로 부른다

AI는 내 컴퓨터 그림을 볼 수 없어요. 대신 파일 이름과 위치를 알려 주면 그 자리에 넣는 코드를 써 줍니다.

처음부터 그림을 넣어 만들기 (제미나이 캔버스) 너는 초등학교 과학 선생님을 돕는 웹 개발자야. 4학년 2학기 과학 '생물과 환경' 단원에서 쓸 '먹이그물 탐험대' 웹앱을 HTML 파일 하나(index.html)로 만들어 줘. 성취기준: [4과14-01] 생태계 구성 요소를 생물 요소와 비생물 요소로 분류 / [4과14-02] 먹고 먹히는 관계를 먹이그물로 표현 / [4과14-03] 인간 활동의 영향과 생태계 보전 [미션] 1. 생물 요소·비생물 요소 바구니에 카드 나누기 (햇빛, 물, 공기, 흙, 온도 / 소나무, 버섯, 개구리 …) 2. 생산자·소비자·분해자로 나누기 (분해자는 버섯·곰팡이·세균만) 3. 먹이사슬 잇기: 벼 → 메뚜기 → 개구리 → 매 (네 칸에 순서대로) 4. 먹이그물 만들기: 먹히는 생물을 먼저 누르고 먹는 생물을 누르면 화살표가 생김 5. 개구리가 사라지면? 먹이사슬 마을과 먹이그물 마을 비교 6. 대기·수질·토양오염 나누기, 실천 다짐 카드 만들기 [지도서 기준] 화살표는 '먹히는 생물 → 먹는 생물' / 광합성 원리는 설명하지 않기 / '생태계평형' 용어는 쓰지 않기 [그림] index.html과 같은 위치의 images 폴더에 그림이 있어. 이 파일 이름 그대로 불러 와 줘. - images/logo.png : 첫 화면 가운데 로고 (가로 최대 380px) - images/bg.jpg : 첫 화면 전체 배경 - images/btn_start.png : 탐험 시작 버튼 / images/btn_check.png : 정답 확인 / images/btn_retry.png : 다시 하기 / images/btn_next.png : 다음 - images/guide_hi.png, guide_good.png, guide_think.png : 안내 캐릭터 (인사, 칭찬, 고민) - images/org/영어이름.png : 생물 카드 (frog=개구리, hawk=매, rice=벼, grasshopper=메뚜기 …) [디자인] 둥근 카드, 두꺼운 검은 테두리의 스티커 느낌, 태블릿·전자칠판에서도 크게 보이게 [저장] 진행 기록은 localStorage에만 저장(서버로 보내지 않기)
이미 만든 앱에 그림만 덧붙이기 지금 앱의 기능은 그대로 두고 그림만 넣어 줘. 그림은 index.html과 같은 위치의 images 폴더에 있어. - 첫 화면 제목 글자 대신 images/logo.png - '시작' 버튼은 images/btn_start.png 그림 버튼으로 (글자는 alt로) - 맞혔을 때는 images/guide_good.png, 틀렸을 때는 images/guide_think.png 캐릭터가 말풍선과 함께 나오게 바뀐 index.html 전체 코드를 생략 없이 다시 보여 줘.
캔버스 미리보기에서 그림이 깨져 보여요! 정상입니다. 캔버스는 내 컴퓨터의 images 폴더를 볼 수 없어요. 내보내기 → 코드 다운로드로 받은 index.html을 images 폴더 옆에 두고 열면(또는 깃허브에 올리면) 그림이 보입니다.

깃허브에 올리기 — 인터넷 사물함 만들기

저장소(repository) = 앱 파일을 넣어 두는 인터넷 사물함. 공개(Public)로 만들면 무료로 웹 주소를 받을 수 있어요.

0가입하기 (처음 한 번)

  1. github.com → Sign up
  2. 이메일 → 비밀번호 → 사용자 이름(username) 정하기
  3. 메일로 온 인증 코드 입력
사용자 이름 = 앱 주소 사용자이름.github.io/저장소이름/이 됩니다. 학생에게 보여 줄 주소이니 짧고 알아보기 쉽게! (예: hongdonedu)
나중에 Settings → Account → Change username으로 바꿀 수 있지만, 그러면 기존 주소도 모두 바뀝니다.

1새 저장소 만들기

오른쪽 위 ＋ → New repository

2이름 짓고 공개로 만들기

  1. Repository name: 영어 소문자·숫자·하이픈 (foodweb) → 초록색 is available 확인
  2. Description(설명)은 한글로 자유롭게
  3. Public 그대로 두기 (무료 Pages는 공개 저장소에서만)
  4. 초록 Create repository
저장소 이름 = 주소 뒷부분 단원별로 light-maze, life-farm, foodweb처럼 짧게 지으면 학생도 기억하기 쉬워요.

3파일 올리는 화면으로

빈 저장소 화면의 uploading an existing file 링크를 누릅니다.
(파일이 이미 있는 저장소라면 Add file → Upload files)

4폴더 안의 것을 모두 끌어다 놓기

  1. 파일 탐색기에서 앱 폴더를 열고 Ctrl+A로 index.html과 images 폴더를 모두 선택
  2. 점선 상자 안으로 끌어다 놓기
  3. 파일 목록에 images/logo.png처럼 폴더 이름까지 보이면 성공
폴더 자체를 끌면? 먹이그물탐험대/index.html처럼 한 단계 안에 들어가 주소가 길어져요. 폴더를 열고 그 안의 내용물을 끌어 주세요. (한 번에 100개까지)

5목록 확인 → Commit changes

  1. 58개 파일이 올라간 것 확인 (index.html이 맨 위)
  2. 맨 아래 Commit changes 칸에 무엇을 올렸는지 한 줄 메모 (생략해도 됨)
  3. 초록 Commit changes 누르기 = 저장 완료

6저장소에 들어갔는지 확인

images 폴더, index.html이 보이면 성공. 이제 사물함은 채웠고, 다음 단계에서 가게 문(웹 주소)을 엽니다.

index.html 이름 확인! index.html.html이나 Index.html이면 주소로 열리지 않아요. 파일을 눌러 ✏️ → 이름 칸에서 고칠 수 있어요.

2main → / (root) → Save

  1. 목록에서 main 선택
  2. 폴더는 / (root) 그대로
  3. Save

31~2분 뒤 새로고침 → 주소 확인

Your site is live at 옆의 주소가 내 앱 주소입니다. Visit site로 열어 보세요.

https://hongdonedu.github.io/foodweb/ └ 사용자 이름 └ 저장소 이름
안 열리면? 1~2분 더 기다린 뒤 Ctrl+F5. 저장소 위 Actions 탭에서 초록 체크(✓)가 뜨면 배포 완료입니다.

넷리파이 — 폴더 끌어다 놓으면 끝

깃허브 없이도 OK. 폴더를 끌어다 놓으면 몇 초 만에 ○○.netlify.app 주소가 생깁니다.

1로그인 (깃허브 계정으로)

app.netlify.com → Log in with GitHub (처음이면 Sign up → GitHub). 계정을 하나 더 만들 필요가 없어요.

2Add new project → 폴더 끌어다 놓기

  1. Projects 화면의 Add new project
